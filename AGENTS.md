# Evorya Digital — notes pour les agents

- Stack : Next.js 14 (App Router), React 18, Tailwind CSS 3, JavaScript (JSX). Pas de TypeScript.
- Alias d'import : `@/*` pointe vers `src/*` (voir `jsconfig.json`).
- Contenu à ne jamais inventer : chiffres, clients, témoignages, équipe. Les coordonnées officielles
  sont dans `src/data/company.js` ; le contenu de la section « Nos projets » est dans `src/data/projects.js`
  (l'objectif de 80 % d'INNVORIQ est un objectif, pas un résultat ; visuels = illustrations conceptuelles).
- Le dossier `ui-ux-pro-max-skill-main/` contient les sources d'un skill et ne fait pas partie du site.
